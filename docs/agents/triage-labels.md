# Triage 標籤

各個 skill 以五個固定的角色描述一張工作項目的狀態。這個檔案把那些角色對應到本儲存庫實際使用的字串。在本機 Markdown 的做法下，標籤就是每個檔案開頭 `Status:` 行的值。

| mattpocock/skills 的標籤 | 本儲存庫使用的標籤 | 意思 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 還沒有人評估過 |
| `needs-info` | `needs-info` | 等提出的人補充資訊 |
| `ready-for-agent` | `ready-for-agent` | 規格完整，可以交給程式代理直接做 |
| `ready-for-human` | `ready-for-human` | 需要人來做 |
| `wontfix` | `wontfix` | 不處理 |

skill 提到某個角色時（例如「貼上可交給代理的標籤」），使用這張表右邊對應的字串。

要改用別的名稱時，修改中間那一欄。
