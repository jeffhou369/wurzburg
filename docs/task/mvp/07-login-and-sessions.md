# 07 — 登入與工作階段

Status: resolved
Blocked by: 03, 05, 06

## 要做什麼

讓人能登入系統。登入頁有「組織帳號」與「系統管理員」兩個入口，兩者走完全分開的路徑，不依帳號自動判斷。

**系統管理員**

- 系統啟動時若還沒有任何系統管理員，用環境變數提供的帳號與初始密碼建立第一個。已經有系統管理員之後，那兩個環境變數不再有任何作用。
- 第一次登入強制修改密碼，新密碼要符合密碼政策，改完才能進入系統。
- 密碼以 Argon2id 雜湊；連續失敗達到上限後暫時鎖定。
- 系統管理員可以建立與停用其他系統管理員；系統至少保留一個啟用中的。
- 忘記密碼時，在主機上執行管理指令重設；沒有網頁上的忘記密碼功能。

**一般使用者**

- 經由驗證來源的介面驗證帳密（實際的 AD 與 RADIUS 由第 21、22 張完成，這裡用測試替身）。
- 第一次登入成功時自動建立帳號。

**驗證來源的選擇**

- 設定頁可以選擇這個園區啟用哪一種驗證來源，同一時間只有一種。AD 與 RADIUS 各自的連線表單由第 21、22 張填入。
- 上線後更改驗證來源前，顯示警告：原有的擁有者帳號將無法登入，名下的登記需要系統管理員改派，並列出受影響的登記筆數。

**其他**

- 登出後工作階段立即失效，按返回鍵看不到需要權限的資料。
- 不在 HTTPS 後面時，登入頁顯示明文傳輸的警告。
- 登入有速率限制。

## 驗收條件

- [x] 沒有任何系統管理員時，以環境變數的帳密可以登入；初始密碼不出現在任何日誌
- [x] 第一次登入後，改密碼之前不能呼叫其他 API
- [x] 新密碼不符合政策（預設至少 12 個字元）時被拒絕
- [x] 已有系統管理員時，改動環境變數後重新啟動，不會新增帳號也不會重設密碼
- [x] 連續失敗達到上限（預設 5 次）後鎖定，時間到（預設 15 分鐘）後恢復；以測試控制的時鐘驗證
- [x] 系統管理員的帳密從「組織帳號」入口登入會失敗，反之亦然
- [x] 一般使用者第一次登入成功後，帳號出現在系統裡
- [x] 系統管理員可以建立、停用另一個系統管理員；停用最後一個啟用中的會被拒絕
- [x] 主機上的管理指令可以重設系統管理員的密碼
- [x] 登出後，原本的工作階段不能再使用
- [x] 更改驗證來源前看得到警告與受影響的筆數
- [x] 不在 HTTPS 後面時登入頁有警告，在 HTTPS 後面時沒有
- [x] 登入成功與失敗都寫入稽核紀錄，且不含密碼
- [x] 關鍵流程有瀏覽器測試：系統管理員首次登入並改密碼
