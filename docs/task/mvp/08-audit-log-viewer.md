# 08 — 稽核紀錄的檢視

Status: ready-for-agent
Blocked by: 03, 05, 06

## 要做什麼

系統管理員可以在「稽核紀錄」頁查看誰在什麼時候做了什麼。清單由新到舊，顯示時間、操作者、來源 IP、動作、對象與變更摘要；摘要較長時可以展開，例如網段變更連帶刪除的登記明細。

各功能的事件由各自的工作項目寫入，這張只負責查詢與顯示。依時間、操作者、動作篩選與匯出屬於 Beta，不在這張的範圍。

## 驗收條件

- [ ] 系統管理員看得到稽核紀錄，由新到舊，伺服端分頁
- [ ] 一般使用者呼叫這個 API 回 403，側欄也看不到入口
- [ ] 每一筆顯示時間（園區的時區）、操作者、來源 IP、動作、對象、變更摘要
- [ ] 帶有明細的紀錄可以展開看到逐筆內容
- [ ] 時間與 IP 以等寬字顯示
- [ ] 沒有任何紀錄時顯示空狀態

## 邊界

- 只修改本功能自己的後端模組、頁面、介面文字與自己那一份 API 描述；共用的檔案不要改。
- 測試需要的稽核紀錄用資料擺設工具準備，不依賴其他尚未完成的功能。
- 契約或資料庫結構有缺漏時，只做最小的補充，並在本檔案的 `## Comments` 記下。
