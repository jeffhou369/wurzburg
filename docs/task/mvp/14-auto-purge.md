# 14 — 自動清除

Status: resolved
Blocked by: 03, 05, 06

## 要做什麼

讓管理表不會累積沒有意義的紀錄：同時符合「未登記」與「離線」的 IP 紀錄，離線超過設定的天數後自動刪除。

- 清除天數是設定值，預設 90 天；設成 0 代表停用自動清除。
- 有擁有者的 IP 紀錄（已登記或已到期）不論離線多久都不會被清除。
- 清除時一併刪除那筆 IP 紀錄的通知去重狀態與已解消的衝突。
- 每次清除在稽核紀錄記下筆數。
- 系統管理員可以在設定頁調整天數。

被清除的位址日後再出現，就是一筆全新的未登記 IP 紀錄。

## 驗收條件

- [x] 未登記且離線滿 90 天的 IP 紀錄被刪除（以測試控制的時鐘驗證）
- [x] 未登記且離線 89 天的不被刪除
- [x] 未登記但在線的不被刪除
- [x] 已登記或已到期的，離線再久也不被刪除
- [x] 天數設成 0 時不清除任何東西
- [x] 天數改成其他值後，行為跟著改變
- [x] 每次清除在稽核紀錄有一筆，寫明筆數；沒有東西可清時不寫
- [x] 系統管理員可以在設定頁修改天數；一般使用者不能
