# 06 — 後端共用機制

Status: resolved
Blocked by: 04

## 要做什麼

建立後端各功能共用的機制與模組之間的介面，讓之後的功能只需要填入自己的模組。

1. **工作階段與授權**：伺服端的工作階段（可撤銷、閒置逾時、Cookie 設 HttpOnly 與 SameSite，在 HTTPS 後面時加 Secure）；依角色與「是不是擁有者」判斷權限的共用檢查；變更類請求的 CSRF 防護。測試環境提供「以某個系統管理員或一般使用者的身分呼叫 API」的輔助，不必真的走登入流程。
2. **設定值**：開發規格第 10 節的全部設定值與預設，可讀可寫。
3. **Secret**：加密後存在資料庫，金鑰由環境變數或掛載檔提供；讀回時只表示「已設定」。
4. **稽核寫入**：一個讓各功能記下「誰、何時、從哪裡、做了什麼、對象、變更摘要」的共用入口，並保證 secret 不會被寫進去。
5. **狀態的推算**：由一筆 IP 紀錄的資料推算出在線狀態、登記狀態、是否即將到期、是否有衝突。表格、登記、通知都用同一份推算。
6. **位址歸屬的查詢**：給一個 IPv4 位址，回答它屬於哪個網段（最長的前綴）、是否在排除範圍內、是否為閘道位址，以及因此該不該有 IP 紀錄。
7. **模組的介面**（先只有介面與測試用的替身）：
   - 採集：輸入一筆 VRF 讀取設定，輸出 ARP 觀測、介面位址、介面名稱，或一個錯誤類別
   - 驗證來源：驗證一組帳密，回傳帳號的資料
   - OUI 查詢：以 MAC 查廠商，預設回答「未知」
   - 寄信：寄出一封含 HTML 與純文字的信；測試環境可以取得寄出的信
8. **一輪讀取結果的處理管線**：一輪的讀取結果依序交給「管理範圍」與「狀態整併」兩個步驟，兩者先是空的。測試環境可以直接送入一輪的讀取結果，不必經過 SNMP。
9. **路由的註冊方式**：每個功能在自己的模組裡註冊自己的 API，不需要修改共用的檔案。

## 驗收條件

- [x] 測試可以用一行以系統管理員或一般使用者的身分呼叫 API
- [x] 未登入的請求回 401；角色不符回 403；兩者都有測試
- [x] 工作階段閒置逾時後失效（以測試控制的時鐘驗證）
- [x] 變更類的請求沒有 CSRF 防護的憑據時被拒絕
- [x] 設定值都有預設，修改後讀得回來
- [x] 存入的 secret 在資料庫中不是明文；API 與日誌都讀不到明文
- [x] 金鑰不存在或錯誤時，應用程式給出清楚的錯誤而不是默默用空值
- [x] 稽核寫入的入口會拒絕或遮蔽 secret
- [x] 狀態的推算涵蓋所有組合，包含「離線 · 已到期」與即將到期的邊界日
- [x] 位址歸屬的查詢涵蓋：互相包含的網段、排除範圍的邊界位址、閘道位址、不屬於任何網段
- [x] 四個模組介面都有測試用的替身，測試可以指定它們的回應
- [x] 測試可以送入一輪的讀取結果並看到管線被呼叫
- [x] 有一份說明，告訴其他工作項目如何註冊路由、寫稽核、讀設定、使用替身

## Comments

已完成 06 — 後端共用機制：
- `internal/auth/`：伺服端工作階段存取（SessionStore）、HttpOnly/SameSite/Secure Cookie、閒置逾時檢查、角色中介軟體（`RequireAuth`、`RequireAdmin`）、CSRF 標頭檢查（`CSRFMiddleware`）與擁有者編輯權限判斷（`CanEditRegistration`）。
- `internal/crypto/`：AES-256-GCM 機敏資料加密處理器，嚴格校驗金鑰長度。
- `internal/settings/`：規格第 10 節預設值、一般設定與 Secret 加密讀寫。
- `internal/audit/`：稽核事件記錄器，自動過濾並以 `[REDACTED]` 遮蔽密碼、金鑰、憑證等欄位。
- `internal/state/`：統一推算在線／離線、未登記／已登記／已到期、即將到期與衝突文字標籤（`state.Compute`）。
- `internal/subnets/`：`Resolver` 支援最長前綴比對（LPM）、排除範圍邊界檢查與閘道位址過濾。
- `internal/interfaces/`：定義採集（`Collector`）、驗證來源（`AuthSource`）、OUI（`OUILookup`）、郵件（`Mailer`）四大介面與完整測試替身（Fakes）。
- `internal/pipeline/`：`PollPipeline` 讀取結果協調處理管線。
- `internal/server/`：支援 `RouteRegistrar` 模組自訂路由掛載。
- `internal/testutil/http.go`：提供一行測試身分呼叫輔助 `NewAuthRequest`。
- `INTERNAL-DEV-GUIDE.md`：撰寫後端共用機制使用與路由註冊指引。
- 所有單元與 MariaDB 容器整合測試全數通過。
