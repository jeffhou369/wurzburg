# 09 — 交換器與 VRF 讀取設定的管理

Status: resolved
Blocked by: 03, 05, 06

## 要做什麼

系統管理員可以在「交換器」頁管理 ARP 來源交換器，以及每台交換器底下的 VRF 讀取設定。

- 交換器的資料：名稱、管理 IP、平台（IOS-XE 或 NX-OS）、SNMP 版本、埠、逾時、備註、是否啟用，以及一個純顯示用的標籤。
- 每台交換器有一到多筆 VRF 讀取設定。每筆有 VRF 的顯示名稱，以及讀取它所需的資料：v3 是 context 名稱，v2c 是該 VRF 專屬的 community。全域 VRF 那一筆固定存在，不能刪除。
- 只有全域 VRF 一筆時，顯示提示：VRF 內的位址不會被看到。
- SNMP 憑證加密保存，儲存後不再顯示，只顯示「已設定」。
- 「測試讀取」按鈕：經由採集的介面對這筆設定讀取一次，顯示讀到幾筆或錯誤類別。
- 停用或刪除一筆 VRF 讀取設定（或整台交換器）時，它名下的 ARP 觀測立即移除。

每台交換器以一張狀態卡呈現。讀取紀錄的顯示由第 11 張填入。

## 驗收條件

- [x] 系統管理員可以新增、編輯、停用、刪除交換器；一般使用者呼叫這些 API 回 403
- [x] 管理 IP、埠、逾時的格式錯誤時回 422 並指出欄位
- [x] 新增交換器時自動帶有全域 VRF 的讀取設定；刪除它會被拒絕
- [x] 可以新增與刪除其他 VRF 讀取設定；v3 需要 context 名稱，v2c 需要 community
- [x] 儲存後的憑證在任何 API 回應中都讀不到，只看得到「已設定」
- [x] 不重新輸入憑證也能修改其他欄位
- [x] 「測試讀取」成功時顯示筆數，失敗時顯示錯誤類別（逾時、認證失敗、連線被拒、無資料）
- [x] 停用一筆 VRF 讀取設定後，只由它看得到的 IP 紀錄變為離線
- [x] 新增、修改、停用、刪除都寫入稽核紀錄，且不含憑證
- [x] 管理 IP 以等寬字顯示；刪除交換器前有確認
