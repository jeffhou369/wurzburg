# 30 — 到期催認

Status: resolved
Blocked by: 19

## 要做什麼

登記的有效期是一年。到期前後，系統寄信到擁有者信箱，請對方重新確認或釋放；催到上限就停，不自動釋放。

**時程**（括號內是預設，都是設定值）

1. 到期前 14 天寄一次。
2. 到期當天寄一次。
3. 之後每 7 天復催一次，最多 4 次。
4. 催完仍未回應就停止寄信。IP 紀錄維持已到期，擁有者與備註保留。

**規則**

- 收件人是擁有者信箱。
- 同一個擁有者信箱同一天有多筆要催，合併成一封。
- 只有最後一次復催副本給系統管理員收件清單。
- 去重鍵包含 IP、到期日與催認的輪次，同一輪不重複寄。
- 重新確認後到期日改變，催認從頭開始；釋放後不再催。
- 寄送失敗的不算已寄，之後會再嘗試。
- 系統管理員可以在設定頁調整提前天數、復催間隔與次數上限。

**信的內容**（使用第 19 張的共用版面）

- 主旨區分即將到期與已到期，並標示是第幾次提醒：`[Würzburg] 請重新確認您的 IP 登記：…`
- 摘要：需要處理的筆數、最早的到期日
- 明細表：IP、目前的狀態（文字，例如「在線 · 即將到期」）、MAC、廠商、網段、裝置類型、備註摘要、上次確認的日期、到期日
- 主要按鈕：「登入後重新確認，延長一年」，連到已篩選為自己待確認的清單
- 次要連結：「若已不使用，請登入後釋放」
- 頁尾：說明未確認的後果——紀錄不會自動刪除，但會標示為已到期，系統管理員可能會與您聯絡
