# 17 — 廠商名稱（本地 OUI）

Status: resolved
Blocked by: 03, 05, 06

## 要做什麼

以本地的 OUI 資料查出每個 MAC 的廠商。查詢與輪詢的路徑上不得有任何對外連線。

- 產品出貨時附一份 OUI 快照，註明來源與日期。
- 實作 OUI 查詢的介面：以 MAC 的前綴比對，資料檔有提供時支援 28 與 36 位的長前綴；查不到回答「未知」。
- 系統管理員可以在設定頁上傳新的資料檔取代現有的，並看到目前資料的版本、匯入的人與時間。
- 匯入後，既有 IP 紀錄的廠商名稱重新計算。
- 系統不依廠商推斷裝置類型。

## 驗收條件

- [x] 出貨的快照可以查出常見前綴的廠商；快照的來源與日期有文件記錄
- [x] 查不到的 MAC 回答「未知」，不是空白或錯誤
- [x] 長前綴優先於 24 位前綴
- [x] 系統管理員可以上傳資料檔；格式錯誤的檔案被拒絕並說明原因，現有資料不受影響
- [x] 上傳後，設定頁顯示新的版本、匯入的人與時間
- [x] 上傳後，既有 IP 紀錄的廠商名稱更新
- [x] 查詢過程沒有任何對外連線（以測試驗證）
- [x] 一般使用者不能上傳
- [x] 匯入寫入稽核紀錄
- [x] 查詢在記憶體或本地索引完成，一輪 25,000 筆的查詢不拖慢整併
