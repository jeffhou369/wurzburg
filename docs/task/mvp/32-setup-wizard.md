# 32 — 設定精靈與未完成清單

Status: ready-for-agent
Blocked by: 09, 12, 19, 21, 22

## 要做什麼

系統管理員第一次登入並改完密碼後，由設定精靈一步一步帶著完成初始設定。精靈重複使用各功能已經做好的表單，不另外實作一份。

**五個步驟**

| 步驟 | 內容 | 測試 |
| --- | --- | --- |
| 1 園區資訊 | 顯示名稱、時區 | — |
| 2 驗證來源 | 選 AD 或 RADIUS，填連線資料 | 以一組帳密測試登入 |
| 3 郵件 | SMTP、系統管理員收件清單 | 寄測試信 |
| 4 第一台交換器 | 管理 IP、SNMP 版本與憑證、VRF 讀取設定 | 測試讀取 |
| 5 檢視網段 | 把發現的網段設為納管或不納管 | — |

- 每一步都可以按「稍後再設定」跳過。
- 第 5 步在第 4 步完成後先觸發一次同步，再列出發現的網段；第 4 步被跳過時，第 5 步說明原因並可直接結束。
- 精靈可以中途離開，下次回來從上次的步驟繼續。
- 精靈可以從設定頁重新開啟。

**園區資訊**（這張負責）：顯示名稱與時區的設定。顯示名稱用在側欄、頁面標題與信件；時區用在所有時間的顯示與排程。

**尚未完成的設定清單**：精靈結束後，系統管理員的首頁顯示一張清單，列出還沒完成的項目與各自的後果，每一項可以直接點進去設定：

- 尚未設定驗證來源：一般使用者無法登入
- 尚未設定郵件：三種通知都寄不出去
- 尚未新增交換器：沒有任何資料
- 有待檢視的網段，或沒有任何納管的網段：管理表是空的
- 尚未啟用 HTTPS：帳密以明文傳輸

全部完成後清單消失。一般使用者看不到這張清單。

## 驗收條件

- [ ] 系統管理員第一次登入並改完密碼後自動進入精靈
- [ ] 五個步驟依序出現，每一步的測試按鈕可用並顯示結果
- [ ] 每一步都能跳過；跳過的步驟出現在未完成清單
- [ ] 中途離開後再進入，從上次的步驟繼續
- [ ] 完成第 4 步後，第 5 步看得到發現的網段並能設定狀態
- [ ] 第 4 步被跳過時，第 5 步有說明且不會卡住
- [ ] 精靈完成過之後，再次登入不會自動開啟；可以從設定頁重新開啟
- [ ] 修改顯示名稱後，側欄與頁面標題跟著改變
- [ ] 修改時區後，畫面上的時間跟著改變
- [ ] 未完成清單的五個項目各自在條件成立時出現、條件解除時消失
- [ ] 在 HTTPS 後面時，「尚未啟用 HTTPS」不出現
- [ ] 全部完成後清單消失
- [ ] 一般使用者看不到精靈與未完成清單，呼叫相關 API 回 403
- [ ] 園區資訊的變更寫入稽核紀錄
- [ ] 關鍵流程有瀏覽器測試：走完整個精靈

## 邊界

- 重複使用第 09、12、19、21、22 張的表單與 API，不複製它們的邏輯。
- 只修改精靈本身、園區資訊的設定、首頁的未完成清單插槽、介面文字與自己那一份 API 描述。
- 需要其他功能的表單配合調整時，只做最小的修改，並在本檔案的 `## Comments` 記下。
