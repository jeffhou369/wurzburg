# 18 — 登記

Status: ready-for-agent
Blocked by: 03, 05, 06

## 要做什麼

讓使用裝置的人自己為位址負責。在 IP 紀錄 Sheet 的「登記」分頁完成下列動作。

**一般使用者**

- 登記一筆未登記的 IP 紀錄，立即成為擁有者，不需要核准。
- 編輯、重新確認、釋放自己是擁有者的登記。
- 開啟別人的登記時是唯讀，並顯示「請聯絡系統管理員」的說明。

**系統管理員**

- 登記任何未登記的 IP 紀錄，擁有者可以指定為自己或任一已存在的帳號。
- 編輯、重新確認、釋放任何一筆登記。
- 把一筆登記改派給另一個已存在的帳號。

**欄位與規則**

- 擁有者信箱必填並做格式校驗。使用 AD 的帳號自動帶入目錄裡的信箱，可以修改；它可以是共用信箱，不決定任何權限。
- 裝置類型（自由文字）、主機名稱、備註皆為選填。備註欄旁註明「所有登入者都看得到」。
- 登記與重新確認把到期日設為當天加上有效期（預設 365 天，可在設定頁調整）。
- 釋放使 IP 紀錄回到未登記，擁有者、擁有者信箱與到期日清除。
- 能不能編輯只看帳號是不是擁有者，與擁有者信箱無關。

API 以「對一組 IP 紀錄執行一個登記動作並回傳逐筆結果」的形式提供；這一張的畫面只處理單筆，批次的畫面由第 27 張完成。

## 驗收條件

- [ ] 一般使用者登記未登記的 IP 紀錄後成為擁有者，狀態變為已登記，到期日是一年後
- [ ] 擁有者信箱空白或格式錯誤時回 422
- [ ] 已有擁有者的 IP 紀錄不能再被別人登記（回 409）
- [ ] 一般使用者編輯、重新確認、釋放別人的登記時回 403
- [ ] 擁有者信箱填的是別人的信箱時，那個人並不因此取得編輯權
- [ ] 擁有者把擁有者信箱改成共用信箱後，自己仍然可以編輯
- [ ] 重新確認後到期日變成當天加一年；已到期的登記重新確認後回到已登記
- [ ] 釋放後 IP 紀錄是未登記，別人可以登記它
- [ ] 系統管理員可以代為登記並指定擁有者、改派、釋放任何一筆
- [ ] 改派的對象不存在時回 422
- [ ] 有效期改成其他值後，新的登記與重新確認使用新的值
- [ ] 每一個動作都寫入稽核紀錄，帶變更前後的摘要
- [ ] 別人的登記以唯讀呈現並有說明；備註欄有「所有登入者都看得到」的說明
- [ ] 關鍵流程有瀏覽器測試：一般使用者登記一筆未登記的 IP 紀錄

## 邊界

- 測試需要的 IP 紀錄與帳號用資料擺設工具準備，不依賴其他尚未完成的功能。
- 授權的共用檢查與狀態的推算由第 06 張提供，這張不重寫。
- 只修改本功能自己的後端模組、Sheet 的「登記」分頁、設定頁中自己的子頁、介面文字與自己那一份 API 描述。
- 契約或資料庫結構有缺漏時，只做最小的補充，並在本檔案的 `## Comments` 記下。
