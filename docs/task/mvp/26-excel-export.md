# 26 — Excel 匯出

Status: ready-for-agent
Blocked by: 15

## 要做什麼

登入的人可以把首頁 IP 表格目前的篩選結果匯出成 Excel 檔。

- 匯出的內容與目前的搜尋、篩選一致，包含全部符合的筆數，不只是當頁。
- 欄位與表格相同，另外把狀態拆成文字欄位：在線狀態、登記狀態、是否即將到期、是否有衝突。不以顏色作為唯一的表達。
- 檔名包含日期與時間（園區的時區）。
- 匯出前顯示將匯出的筆數。
- 直接產生並下載，不做背景工作。
- 一般使用者與系統管理員匯出的內容相同，因為兩者在畫面上看到的也相同。

開始前查最新文件，決定 Excel 程式庫與版本。

## 驗收條件

- [ ] 套用篩選後匯出，檔案中的筆數與畫面上的總筆數相同
- [ ] 沒有套用篩選時匯出全部 IP 紀錄
- [ ] 檔案可以用試算表軟體開啟
- [ ] 狀態欄位是文字（例如「在線」「未登記」）
- [ ] IP 與 MAC 是文字格式，不被試算表軟體改成數字或日期
- [ ] 時間使用園區的時區，並標示時區
- [ ] 檔名包含日期與時間
- [ ] 以 `=`、`+`、`-`、`@` 開頭的使用者輸入不會被當成公式執行
- [ ] 25,000 筆可以在請求逾時之前完成下載
- [ ] 未登入呼叫回 401

## 邊界

- 沿用第 15 張的查詢與篩選條件，不另外實作一份。
- 只修改本功能自己的後端模組、表格工具列上的匯出按鈕、介面文字與自己那一份 API 描述。
- 契約或資料庫結構有缺漏時，只做最小的補充，並在本檔案的 `## Comments` 記下。
