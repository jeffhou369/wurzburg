# 04 — 完整的資料庫結構與資料擺設工具

Status: resolved
Blocked by: 01

## 要做什麼

一次建好 MVP 需要的全部資料表，並提供一套讓測試「直接擺出某個情境」的工具。這是讓後面的功能可以並行開發的前提：每個功能的測試用這套工具準備自己需要的前置資料，不必等上游的功能做完。

**資料表**（名稱可調整，但要一次到位）：交換器、VRF 讀取設定、讀取紀錄、網段、閘道位址、排除範圍、IP 紀錄、ARP 觀測、IP 變更事件、衝突、使用者、工作階段、OUI 資料與匯入紀錄、通知紀錄、通知狀態、稽核紀錄、設定。

要表達的規則：

- IP 紀錄以 IPv4 位址唯一。
- ARP 觀測是「IP 紀錄 × VRF 讀取設定」目前的一筆，帶 MAC、介面、ARP 類型、最後見到時間與未見輪數。
- 網段只有一個狀態（待檢視、納管、不納管）；不納管必有原因。
- 擁有者是對使用者的參照；擁有者信箱是登記上的獨立欄位。
- 衝突有三種狀態，一筆 IP 紀錄同時最多一筆尚未解消的衝突。
- 使用者區分一般使用者與系統管理員，以及它來自哪一種驗證來源。
- 時間一律以 UTC 儲存。

**資料擺設工具**：測試可以用一兩行擺出下列情境，並且各功能可以在自己的檔案裡擴充它：

- 系統管理員與一般使用者
- 交換器與 VRF 讀取設定，以及它們的讀取紀錄
- 各種狀態的網段、排除範圍、閘道位址
- 各種組合的 IP 紀錄：在線或離線、未登記／已登記／已到期、有無衝突
- ARP 觀測、變更事件、衝突、通知狀態
