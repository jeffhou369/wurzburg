# 25 — 衝突的偵測

Status: ready-for-agent
Blocked by: 13

## 要做什麼

在整併每一輪的 ARP 觀測時，判斷某個 IP 的 MAC 是否出現需要系統管理員裁決的不一致，並讓人看得到。

每一輪把某個 IP 目前所有 ARP 觀測的 MAC 整理成一個集合，與採信 MAC 比較：

| 情況 | 條件 | 處理 |
| --- | --- | --- |
| 並存 | 集合中有兩個以上不同的 MAC | 開衝突 |
| 有擁有者的 IP 換了 MAC | IP 紀錄有擁有者；集合只有一個 MAC，且與採信 MAC 不同 | 開衝突，登記不變 |
| 未登記的 IP 換了 MAC | IP 紀錄沒有擁有者；集合只有一個 MAC，且與採信 MAC 不同 | 不開衝突；採信 MAC 改為新的，記下 MAC 變更事件 |

- 多台交換器回報同一個 IP、同一個 MAC 是正常情況，不算衝突。
- 一筆 IP 紀錄同時最多只有一筆尚未解消的衝突；已經有未處理或處理中的衝突時不再開新的，只更新最近見到的時間與涉及的 MAC。
- 衝突記錄每個 MAC 出現在哪台交換器、哪個 VRF，以及首次與最近見到的時間。
- 未處理的衝突，若不一致自行消失（集合恢復成只有採信 MAC），自動變成已解消並註記為自行消失。

畫面：

- 「衝突」頁列出衝突：IP、涉及的 MAC、來源、首次與最近見到的時間、狀態（未處理、處理中、已解消，都有文字）。
- 側欄的「衝突」顯示未處理的數量。
- 新衝突出現時顯示 Toast。
- 一般使用者可以檢視，不能裁決。

裁決由第 31 張完成。

## 驗收條件

- [ ] 同一個 IP 在同一段時間有兩個不同的 MAC 時開一筆衝突，不論有沒有擁有者
- [ ] 有擁有者的 IP 換成另一個 MAC 時開一筆衝突；採信 MAC 與登記都不變
- [ ] 未登記的 IP 換成另一個 MAC 時不開衝突；採信 MAC 更新，並有一筆 MAC 變更事件
- [ ] 兩台交換器回報同一個 IP、同一個 MAC 時不開衝突
- [ ] 已有尚未解消的衝突時，同樣的不一致不會再開第二筆
- [ ] 衝突的詳細資料列出每個 MAC 的來源交換器、VRF、首次與最近見到的時間
- [ ] 未處理的衝突在不一致消失後自動已解消，並註記為自行消失
- [ ] 側欄的數字只計未處理的
- [ ] 衝突頁每一筆的狀態都有文字，不只靠顏色
- [ ] 有衝突的 IP 紀錄在 API 回應中標示有衝突
- [ ] 一般使用者看得到衝突清單

## 邊界
