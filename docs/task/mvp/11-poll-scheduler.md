# 11 — 輪詢排程、重試與讀取結果

Status: ready-for-agent
Blocked by: 03, 05, 06

## 要做什麼

讓系統每 3 分鐘自動對所有啟用中的 VRF 讀取設定讀取一輪，並讓系統管理員看得到每次讀取的結果。

- 每一輪對每筆啟用中的 VRF 讀取設定呼叫採集，把成功的結果交給處理管線。
- 單筆讀取失敗時立即重試一次，仍失敗就略過到下一輪；總嘗試次數固定為 2。
- 一筆失敗不影響其他的，包含同一台交換器上的其他 VRF。
- 不同交換器之間有上限地並行（預設 12）；同一台交換器上一次只讀一筆。
- 上一輪還沒結束時，下一輪不重疊啟動，並讓介面知道「本輪未完成」。
- 每次讀取都記錄：開始與結束時間、成功或失敗、是否重試、筆數、錯誤類別。
- 系統管理員可以按「立即同步」觸發一輪。
- 讀取紀錄超過保留期（預設 30 天）後清除。

畫面：交換器頁的狀態卡顯示每筆 VRF 讀取設定最近一次讀取的時間、結果、筆數與錯誤；進行中顯示「同步中」，失敗以徽章加可展開的錯誤呈現，不用全螢幕阻擋。

## 驗收條件

- [ ] 時鐘前進 3 分鐘後，每筆啟用中的 VRF 讀取設定被讀取一次
- [ ] 停用的交換器與 VRF 讀取設定不被讀取
- [ ] 第一次失敗、第二次成功時，結果被採用，紀錄標示有重試
- [ ] 兩次都失敗時，那一筆在本輪被略過，其他的照常完成，紀錄有錯誤類別
- [ ] 失敗的那一筆沒有把任何結果交給處理管線
- [ ] 同一台交換器上不會同時有兩筆讀取在進行
- [ ] 同時進行的讀取數不超過並行上限
- [ ] 上一輪未結束時不會啟動第二輪，輪詢狀態回報「本輪未完成」
- [ ] 「立即同步」會啟動一輪；已有一輪在進行時不重複啟動；一般使用者呼叫回 403
- [ ] 交換器頁看得到每筆 VRF 讀取設定最近一次的結果，失敗可展開看錯誤
- [ ] 讀取紀錄超過保留期後被清除
- [ ] 手動同步寫入稽核紀錄

## 邊界

- 測試使用採集介面的替身，並用資料擺設工具準備交換器與 VRF 讀取設定；不依賴第 09、10 張。
- 只修改本功能自己的後端模組、交換器頁中讀取結果的部分、介面文字與自己那一份 API 描述。
- 契約或資料庫結構有缺漏時，只做最小的補充，並在本檔案的 `## Comments` 記下。
