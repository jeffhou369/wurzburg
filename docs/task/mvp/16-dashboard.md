# 16 — 儀表板

Status: resolved
Blocked by: 03, 05, 06

## 要做什麼

首頁上半部的儀表板：登入的人一眼看得到園區的現況。

- 一列 KPI 卡：納管的 IP 總數、在線、離線、未登記（在線）、已到期、衝突（未處理）。每張卡有小標、數字與一行說明；衝突的數字用危險色。
- 一張同步狀態卡：ARP 來源交換器的數量、最近一次同步的時間與是否成功、有幾筆 VRF 讀取設定在最近一輪失敗、本輪是否未完成。
- 數字與 IP 表格使用同一份狀態的推算，兩邊必須一致。

點擊數字連動下方表格的篩選屬於 Beta，不在這張的範圍。

## 驗收條件

- [x] 六個數字與同樣條件下 IP 表格的筆數一致
- [x] 未登記的數字只計在線的；已到期的數字不論在線與否
- [x] 衝突的數字只計未處理的
- [x] 同步狀態卡顯示最近一次同步的時間（園區的時區、等寬字）與結果
- [x] 最近一輪有失敗時顯示失敗的筆數；本輪未完成時有提示
- [x] 還沒有任何交換器或資料時顯示引導文字，而不是一排零
- [x] 每個數字都有文字說明，不只靠顏色
- [x] 一般使用者與系統管理員看到相同的數字
- [x] KPI 卡在窄螢幕換行而不裁切
