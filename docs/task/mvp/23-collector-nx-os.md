# 23 — 採集模組：NX-OS

Status: ready-for-agent
Blocked by: 10

## 要做什麼

讓平台設為 NX-OS 的交換器也能被讀取，產出與 IOS-XE 相同的三樣東西：ARP 觀測、介面位址、介面名稱。

第 10 張已經建立 SNMP v2c／v3、VRF 與錯誤分類的共用部分。這一張依第 02 張的摘要文件，處理 NX-OS 與 IOS-XE 不同的地方，例如 VRF 的讀取方式、介面的命名、表的內容差異。平台差異全部留在採集模組內部，模組對外的輸出不變。

## 驗收條件

- [ ] 回放第 02 張的 NX-OS 測試資料檔，產出的 ARP 觀測、介面位址、介面名稱與預期相符
- [ ] v2c 與 v3 都有測試
- [ ] 非全域的 VRF 有測試
- [ ] invalid 的列被忽略；IPv6 的列被丟棄
- [ ] secondary 位址出現在介面位址中
- [ ] IOS-XE 的既有測試全部仍然通過
- [ ] 命令列入口可以指定平台為 NX-OS
- [ ] 第 02 張摘要文件中 NX-OS 找不到依據的項目，在文件中列為實機驗證時優先確認

## 邊界

- 這張在輔助測試接縫驗證：輸入測試資料檔，檢查模組的輸出。
- 只修改採集模組，且不改變它對外的輸出。
