# 15 — 首頁的 IP 表格與篩選

Status: resolved
Blocked by: 03, 05, 06

## 要做什麼

首頁下半部的 IP 表格：登入的人可以在這裡找到任何一筆 IP 紀錄。

- 欄位：狀態、IP、MAC、廠商、裝置類型、網段、交換器、擁有者、到期日、最後見到。
- 狀態以燈號加文字呈現，並能表達組合，例如「在線 · 未登記」「離線 · 已到期」；有衝突時顯示「衝突」並優先呈現；即將到期有標示。
- 離線的列以灰階顯示，資料仍可選取。
- 搜尋：IP、MAC、擁有者、主機名稱、備註。
- 篩選（膠囊）：網段、交換器、在線狀態、登記狀態、即將到期、衝突。
- 伺服端分頁、排序與篩選。
- 每一列前面有勾選框，可以多選，也可以一次勾選目前篩選結果的全部。勾選後的批次動作由第 27 張填入。
- 列尾可以複製 IP。點一列開啟 IP 紀錄的 Sheet（內容由第 13、18 張填入）。
- 一般使用者與系統管理員看到相同的資料與欄位。

## 驗收條件

- [x] 表格顯示上列欄位；IP、MAC、時間以等寬字顯示，時間用園區的時區
- [x] 狀態一定有文字，不只靠顏色；組合狀態正確呈現
- [x] 離線的列是灰階，但仍可選取與開啟
- [x] 以 IP 的一部分、MAC、擁有者、主機名稱、備註都搜尋得到
- [x] 每一種篩選都正確，多個篩選同時套用時取交集
- [x] 篩選條件反映在網址上，重新整理或從連結開啟時保持不變
- [x] 25,000 筆的資料下，換頁、排序、篩選的回應在可接受的時間內
- [x] 可以勾選多筆；「全選篩選結果」選到的是全部符合的筆數而不只是當頁
- [x] 複製 IP 可用
- [x] 沒有符合的資料時顯示空狀態
- [x] 未登入呼叫回 401
- [x] 在 375 到 1440px 寬度下可讀，長的內容換行而不裁切
