# 擁有者是帳號，擁有者信箱不決定權限

PRD 的 IP 紀錄同時有帳號與信箱兩個欄位，SA 建議「信箱或帳號任一符合目前登入者即可編輯」（Q-04）。我們決定擁有者就是完成登記的那個帳號，編輯權限只看帳號；擁有者信箱降為聯絡欄位，只用來收到期催認。理由是權限必須建立在系統驗證過的東西上，而登入帳號是唯一在 AD 與 RADIUS 兩邊都驗證過的身分：RADIUS 只回答帳密對不對，系統拿不到也無法驗證使用者的信箱。

## 考慮過的做法

- **擁有者是信箱**：可以直接替別人登記，但 RADIUS 使用者的信箱是自己填的，無法驗證；填共用信箱時也沒有人能編輯。
- **帳號或信箱任一符合**（PRD 的 SA 建議）：RADIUS 使用者只要把自己的信箱填成別人的，就能取得別人登記的編輯權。

## 後果

- 擁有者信箱可以是共用信箱，也可以不是擁有者本人的。
- 替同事登記後，要由系統管理員改派給對方的帳號。
- 一個園區只啟用一種驗證來源，確保一個帳號對應一個人。
- 上線後更改驗證來源，原有的擁有者帳號將無法登入，名下的登記需要系統管理員改派。
- 擁有者離職後帳號無法登入，登記會在到期後停在已到期，由系統管理員改派或釋放。
